1. What is the difference between git clone and git pull?

`git clone` is used once to create a local copy of an entire remote repository, setting up the project on your machine. In contrast, `git pull` is used repeatedly to fetch and integrate ongoing changes from the remote repository into your existing local branch, keeping your copy up to date.

2. Write the command to create a new branch named feature-login.

git checkout -b feature-login

3. What does git status show?

The git status command shows the current state of your working directory and staging area. 

4. Explain what a Pull Request (PR) is and why teams use it.
A Pull Request (PR) is a request to merge code from one branch into another, often from a feature branch into the main branch. Teams use PRs to review code collaboratively.

5. Explain the purpose of git add and git commit. 

The purpose of git add is to stage changes, preparing them to be included in the next commit. Once changes are staged, git commit is used to record those changes in the repository with a descriptive message.
