1.What is the difference between git clone and git pull? (5 pts)
-git clone Creates a copy of a remote repository on your local machine.
git pull Updates your local repository by fetching and merging changes

5.Explain the purpose of git add and git commit. (10 pts)
-git add Stages changes  so they’re ready to be committed.
git commit Records the staged changes in the repository’s history with a message describing the update.
